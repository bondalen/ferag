## Модель задач и правила

Полные правила формирования структуры задач (задача = действие → состояние объекта; DAG зависимостей; ацикличность; каноническая задача и ссылка вида A*B) — в [RULES-tasks.md](../project/RULES-tasks.md).

**Существующие задачи** в данном файле не меняются: они проверены на соответствие правилам; противоречий нет (формулировки соответствуют модели «действие над объектом → состояние»; ссылочная нотация A*B и явные зависимости пока не используются). При добавлении новых задач и при переструктурировании блоков руководствоваться RULES-tasks.

**Кратко:** идентификатор задачи — путь в иерархии по объектам (глубина не ограничена). Одна задача может быть общей подзадачей для нескольких других; тогда в чужом дереве она задаётся ссылкой **локальный_путь*канонический_ID** (например `4.6.12.4.8*3.8.12`). Редактирование и статус — только у канонической задачи. Зависимости образуют DAG; циклы недопустимы.
