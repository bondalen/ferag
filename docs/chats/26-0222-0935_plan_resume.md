**2.1** В обработчике `POST /rags/{rag_id}/chat` после успешного ответа LLM:
- Добавлены две записи `ChatMessage` (user и assistant) с `db.add()` и `db.commit()`.

**2.2** Эндпоинт `GET /rags/{rag_id}/chat/messages`:

**3.2** В `ChatView.vue`:
- В `onMounted` вызов `getChatMessages(ragId)`, маппинг ответа в `{ id?, role, text: content, contextUsed }`, запись в `messages`.

- В `v-for` ключ: `msg.id ?? \`local-${i}\``.

## Решение по скользящему окну

Скользящее окно (передача последних K пар в LLM) не выносится в отдельный шаг. Схема сжатия (резюме старой части + последние K пар + текущий вопрос + RAG-контекст) покрывает и накопление контекста последних реплик, и длинные диалоги. Реализация — по задаче 9.13.

## Критерии успеха (выполнены для шагов 1–3)

- Пользователь открывает «Диалог» по RAG → видит ранее сохранённые реплики (если были).
- Отправляет новый вопрос → получает ответ; после перезагрузки страницы пара отображается в истории.
- В БД в `chat_messages` появляются записи с role user/assistant для данного RAG и пользователя.
